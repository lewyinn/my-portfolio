# my-portfolio

Repository website portfolio pribadi **Moch. Ridho Kurniawan** (Software Engineer).

## Tech Stack

- **Framework**: Next.js 16 (App Router) & React 19
- **Bahasa**: TypeScript
- **Styling & Animasi**: Tailwind CSS v4, Motion, Lenis
- **Konten (Proyek & Blog)**: Velite + MDX (`remark-gfm`, `rehype-pretty-code`, `shiki`)
- **Quality & Testing**: Vitest, ESLint, Prettier

## Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.
