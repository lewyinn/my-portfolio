## Tantangan Awal

Pengelolaan Praktik Kerja Lapangan (PKL) di sekolah melibatkan banyak peran sekaligus: Superadmin platform, Admin Sekolah & Hubin, Admin Perusahaan mitra, Siswa peserta, hingga Orang Tua/Wali. Sebelum sistem terpadu hadir, penempatan siswa di perusahaan mitra, verifikasi kehadiran berbasis lokasi, pencatatan jurnal harian, evaluasi nilai industri, sampai penerbitan sertifikat dan tracer alumni masih terpisah di banyak dokumen serta grup chat.

<Callout title="INTI MASALAH">
  Sekolah, perusahaan mitra, siswa, dan orang tua membutuhkan satu ekosistem data PKL multi-tenant
  yang sinkron secara real-time, baik lewat dashboard web untuk manajemen maupun aplikasi mobile
  untuk aktivitas harian.
</Callout>

## Solusi & Fitur Utama

Internity dibangun sebagai platform SaaS multi-sekolah (isolasi data per `school_id`) yang menyatukan seluruh alur PKL dari hulu ke hilir melalui web app dan aplikasi mobile yang terhubung ke satu API terpusat.

## Peran & Tech Stack

Seluruh modul utama sudah selesai dibangun dan saat ini berada pada tahap finalisasi progress 90%. Di proyek ini, arsitektur sistem dipecah menjadi tiga layer yang saling terintegrasi:

- **Web App (`Vue.js`)**: Antarmuka SPA menggunakan Vue 3, TypeScript, Vite, Tailwind CSS v4, shadcn-vue (Reka UI), Pinia, TanStack Query & Table, serta VeeValidate + Zod. Dilengkapi visualisasi grafik ECharts, peta lokasi geofence Leaflet, verifikasi liveness selfie MediaPipe, multi-bahasa `vue-i18n` (ID/EN), serta notifikasi real-time via Laravel Echo (Pusher WebSocket) dan Firebase FCM.
- **Mobile App (`Flutter`)**: Aplikasi Android/iOS untuk siswa dan orang tua dalam melakukan presensi geofence + selfie, pengisian jurnal harian, pengajuan izin, pairing wali (_guardian monitoring_), hingga menerima notifikasi push langsung.
- **Backend & Infrastruktur (`Laravel`)**: REST API berbasis Laravel 13 & PHP 8.3 yang berjalan di atas Laravel Octane + FrankenPHP dengan autentikasi Laravel Sanctum, PostgreSQL + PgBouncer, Redis, MinIO (object storage S3 untuk file lampiran dan media), `barryvdh/laravel-dompdf` & `PhpSpreadsheet` untuk generator dokumen, serta microservice Rust (`data-stream`) untuk pemrosesan ekspor PDF/ZIP berkecepatan tinggi di dalam container Docker.
