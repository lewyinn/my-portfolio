## Tiga Metrik Utama yang Perlu Dipahami

Core Web Vitals adalah kumpulan metrik dari Google untuk mengukur seberapa nyaman sebuah halaman saat diakses pengunjung asli, baik dari kecepatan tampil, kestabilan tata letak, maupun responsivitas saat tombol diklik.

## Quick Wins Optimasi di Next.js

- Gunakan komponen gambar bawaan (`next/image`) lengkap dengan dimensi eksplisit dan flag `priority` hanya untuk visual utama di atas lipatan.
- Kurangi ukuran JavaScript klien dengan menjaga komponen statis tetap menjadi **Server Components**, sementara animasi interaktif dibatasi pada elemen kecil yang membutuhkannya.
- Manfaatkan static rendering atau caching untuk halaman artikel dan portofolio agar TTFB tetap rendah.
